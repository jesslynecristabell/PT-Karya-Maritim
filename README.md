# PT-Karya-Maritim
PT Karya Maritim Dirgantara merupakan perusahaan yang bergerak di bidang logistik serta kegiatan ekspor dan impor yang berlokasi di Cengkareng Timur, Jakarta Barat. Perusahaan ini menjalankan kegiatan yang berkaitan dengan pengelolaan logistik dan administrasi operasional untuk mendukung kelancaran proses bisnis.
